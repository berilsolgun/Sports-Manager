Sports Manager - User Manual

Requirements

  • Windows 10 or Windows 11
  • Java Runtime 21 or newer

Installation

  1. Run SportsManagerSetup.exe.
  2. Choose an installation folder or keep the default location.
  3. Select the desktop shortcut option if needed.
  4. Launch Sports Manager from the Start Menu or desktop shortcut.

Starting a Game

  1. Select Football or Volleyball.
  2. Select New Game.
  3. Choose the team you want to manage.
  4. Select a tactic.
  5. Choose the match-day squad and starting lineup.
  6. Use the dashboard to view standings, schedule, squad, and match results.

Playing Matches

Use Simulate Week to advance the current gameweek. Before the player's match, the application asks for tactical and lineup choices. During the live match, phases can be played step by step. Between phases, the manager can change tactic and make substitutions.

Save and Load

Use Save Game on the dashboard to create a JSON save file. The save stores the selected sport, season, current week, teams, players, tactics, lineups, fixtures, match results, match events, and injuries.

To continue later, choose the same sport from the opening screen and select Load Game. Pick the saved JSON file to restore the season.

Season End

When all fixtures are played, the season-end screen displays the champion and final standings. The manager can continue to the next season or return to the main menu.

Notes

  • The installer does not install Java. The project requirements assume that the target computer already has a recent Java Runtime installed.
  • If the application does not start, check Java with:
java -version
